# Phase 7: the first simulated games

`association sim game HOME AWAY [--season] [--as-of] [--n] [--seed] [--pbp] [--json] [--home-roster] [--away-roster]` and `association sim replay EVENT_ID [--n] [--seed] [--pbp] [--json]` are the step; `results/` holds recorded runs on this checkout's `sim.duckdb` (built 2026-10-11) and `nba.duckdb` (copied 2026-09-24), named by matchup or event and date. Recorded 2026-10-11: `sim game NY BOS --n 1000 --seed 7 --pbp` in 7 s wall (about 2 s to estimate the rates and build the rotations, the rest the 1,000 games); `sim replay 401705759 --n 1000 --seed 7` (Denver at Houston, 2025-04-13, real result DEN 126-111) in 8 s. These are the first simulated games and are NOT yet validated: step 8's replay harness with the home-win-rate and team-strength baselines is the measurement.
