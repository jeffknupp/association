# Phase 8: the replay validation

`uv run association sim validate --season 2025 --from 2025-01-01 --n 200 --seed 7 --out scripts/sim_p8/results/validate_2025_from_2025-01-01_<date>.md` replays every held-out game with `game.prepare_replay` (the players who appeared, the box five, rates from games before that day) and writes the report (`sim/validate.py`): Brier scores against the home-win rate, a team-strength logistic fit on point-in-time net ratings and ESPN's pre-game probability; the margin PIT histogram; totals; the league's rates over the set; player 80% interval coverage and minutes error. The per-game checks are written beside the report as `.json` for comparing two runs. `results/` holds every recorded run, named by season, start date and run date. The first run sets the tolerances; a later change is accepted only if no metric gets worse beyond noise.
